# Bank Smart Contracts Blockchain Project

> A blockchain-based banking system using Smart Contracts for secure, transparent, and decentralized financial transactions.

![BANK SMART CONTRACT](https://user-images.githubusercontent.com/28294942/166160981-ea06b291-39fd-448b-8634-82164cd0911a.png)

## About

This project demonstrates how smart contracts can be used to build a decentralized banking system on the blockchain. It covers core banking operations such as deposits, withdrawals, and balance inquiries — all executed through auditable smart contracts.

## Features

- **Smart Contract–Powered Banking**: All transactions are recorded on-chain for full transparency.
- **Secure & Transparent**: Immutable ledger ensures tamper-proof record keeping.
- **Decentralized**: No central authority; transactions are verified by the network.

## Tech Stack

- **Blockchain**: Ethereum
- **Smart Contracts**: Solidity
- **Development Framework**: Truffle / Hardhat

## Getting Started

### Prerequisites

- Node.js (v16+)
- Truffle or Hardhat
- MetaMask browser extension
- Ganache (local blockchain for testing)

### Installation

```bash
git clone https://github.com/RajgopalPandilwar/Bank-Smart-Contracts-Blockchain-Project.git
cd Bank-Smart-Contracts-Blockchain-Project
npm install
```

### Deploy Contracts

```bash
# Compile smart contracts
truffle compile

# Deploy to local network
truffle migrate

# Deploy to testnet (e.g., Goerli)
truffle migrate --network goerli
```
